# CSV2S3 Python AWS File Upload System

A Python-based application that uploads CSV files to an AWS S3 bucket using the Boto3 library.

## 🚀 Features
- Upload CSV files to Amazon S3
- Uses AWS SDK for Python (Boto3)
- Simple and lightweight implementation
- Easy to configure AWS credentials

## 📂 Project Structure

├── upload.py
├── read_s3.py
├── data.csv
├── requirements.txt
└── README.md

## 🛠️ Technologies Used
- Python 3
- AWS S3
- Boto3
